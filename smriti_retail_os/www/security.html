📖 Security Governance Policies

SMRITI's Security & Workflow Center maps directly to standard backend modules. Access is tier-restricted:

• Security Architect (Administrator): Absolute core authority to Create/Edit/Delete system Roles, manage the complete Workflow state-machine engines, and customize Workflow States.
• Store Manager: Retail-scoped access. Can onboard Users, activate/deactivate System Users, bind existing Roles/Role Profiles, reset passwords, manage row-level permissions restricted to Company & Warehouse, and process pending approvals.
