## 6. License Secret Vulnerability (Phase 1)

`smriti_retail_os/license/key_validator.py` — `_get_secret()` (line 84):

**Current behavior**: Falls back to `_FALLBACK_SECRET` without checking `frappe.conf.developer_mode`. In production with no secret configured, it silently uses the dev key and logs an error — but does NOT throw.

**Risk**: Any instance with no `smriti_license_secret` in `site_config.json` and no env var will silently validate license keys against a publicly known fallback secret.
