## How to Use This Document

After each pilot, complete one Success Story using the template below.
The first story will be Tattly Threads. Subsequent stories build the proof library.

A strong success story answers three questions a prospect always asks:
1. "Has anyone else done this?"
2. "What actually happened?"
3. "Is this relevant to my situation?"
