# COMM-05 — PSV Sales Battlecard
**Sprint**: PSV-COMM-001 Wave 3
**Audience**: Salesperson (internal tool — not shared with prospect directly)
**Purpose**: Enable 2-minute value articulation in any conversation
**Format**: Quick-reference card — memorize or carry printed

---

## The Core Comparison (5 rows, 2 minutes)

| What Retailer Does Today | What PSV Does |
|--------------------------|---------------|
| Excel spreadsheet — updated manually, always stale | **Live Visibility** — sell-through updates with every data entry |
| Manual calls to distributor to check stock | **Automated Alerts** — WOC warnings before stockout happens |
| Guesswork replenishment — order when someone complains | **WOC-Driven Decisions** — reorder triggered by data, not phone calls |
| Dead stock discovered only during physical audit | **Dead Stock Detection** — 60-day inactivity flagged automatically |
| Reactive — fix problems after they happen | **Proactive** — PSV surfaces problems before they cost money |

## Competitive Positioning

### PSV vs "We Use Excel"

| Dimension | Excel | PSV |
|-----------|-------|-----|
| Data freshness | Days/weeks old | Updated each upload cycle |
| WOC calculation | Manual, error-prone | Automatic, formula-governed |
| Dead stock detection | Never, unless someone looks | Automatic at 60 days |
| Multi-location view | Separate sheets, no consolidation | Single network view |
| Alert system | No alerts | WOC Critical/Warning alerts |
| Effort | Hours per week rebuilding | 20 min/week upload |

**Close**: "Excel is a tool. PSV is an intelligence layer on top of your distribution."

---

### PSV vs "We Have an ERP"

| Dimension | ERP | PSV |
|-----------|-----|-----|
| Scope | Company-owned warehouse stock | Distributor stock (channel visibility) |
| Data source | Your transactions | Distributor secondary sales |
| Sell-through tracking | No (ERP stops at invoice) | Yes — tracks what distributor sold |
| WOC at distributor level | No | Yes |
| Dead stock at distributor | No | Yes |
| Brand-distributor sync | No | Yes — reconciliation cycle |

**Close**: "ERP shows what you dispatched. PSV shows what the distributor sold.
Those are two different numbers — and the gap between them is your risk."

---

### PSV vs "We Already Call Our Distributors"

| Dimension | Phone Calls | PSV |
|-----------|------------|-----|
| Accuracy | Depends on distributor honesty | Data-verified |
| Frequency | Weekly/monthly at best | Continuous |
| Coverage | One at a time | All distributors simultaneously |
| Action lead time | After the problem | Before the problem |
| Documentation | None | Audit trail |

**Close**: "How do you know if the number they gave you is accurate?"

## Qualification Questions (Ask Before Pitching)

```
1. "Aapke kitne distributors hain?"
   (< 5 = Starter tier | 6-20 = Growth | 20+ = Enterprise)

2. "Abhi distributor stock kaise track karte ho?"
   (Excel / ERP / phone calls / nothing = determines pitch angle)

3. "Pichle 6 mahine mein koi stockout issue hua?"
   (Yes = use Scenario 1 | No = use Dead Stock angle)

4. "Distributor apna stock data share karta hai?"
   (Yes = smooth onboarding | No = pilot trust conversation needed)

5. "Pilot decision kaun lega — aap ya distributor?"
   (Brand = direct close | Distributor = COMM-02 script needed)
```
